### LUKS unlock chain

1. Initrd force-loads Surface aggregator + HID modules (else password prompt
   has no keyboard input).
2. Tries USB keyfile at `/usb-key/.luks/surface.key` on the **Ventoy USB**
   (UUID `223C-F3F8`) for up to 1 second.
3. Falls back to manual password if USB not present.

## Restore procedure (if redesign goes wrong)

The bootable artefacts that matter:

1. **GPT partition table** — restorable via `sgdisk --load-backup` (snapshot
   currently in `snapshots/partition-table.txt`; for binary backup, run
   `sudo sgdisk --backup=... /dev/nvme0n1` separately to an external drive).
2. **ESP contents** — back up `/boot/efi/` (37 MiB) to external before changes.
3. **/boot kernel + initrd** — back up `/boot/` (407 MiB) to external before changes.
4. **LUKS header** — back up via `cryptsetup luksHeaderBackup
   --header-backup-file=...` — without this, the encrypted pool is unrecoverable
   if header damage occurs.
5. **NixOS configuration** — already in git at `~/git/cloud-unix/`, source survives
   re-installation.
6. **User data on btrfs pool** — needs full `btrfs send` / rsync to external
   before any partition operation.
